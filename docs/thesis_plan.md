## 1. 引言 (8-10页)
### 1.1 研究背景与项目简介

本项目旨在开发一个基于 AI 的口试评价系统——ChatExaminer。简而言之，ChatExaminer 通过自动生成与课程内容紧密相关的问题，并根据学生的回答在实时对话中动态调整问题，从而模拟真实的口语考试环境。可以这么理解：想象一下，当你参加考试时，老师会根据你的回答及时提出后续问题，并根据你的表现进行评价；ChatExaminer 正是利用大语言模型和状态机机制，试图复现这种个性化的互动式口试体验（见文献[1,2]）。

在目前大多数自动评价系统中，评价往往局限于对静态题目的打分，这样的方法缺乏对考试过程中的互动和动态反馈的捕捉（见文献[3,4,5,6]）。因此，本项目希望通过设计一个能实时调整问题和提供多维度评价反馈的系统，来弥补这一不足。

### 1.2 小型文献综述

现有研究主要集中于静态题目的自动打分和预设标准的评价模型，但这些方法无法充分反映考生在真实口试中的应变能力和理解深度（见文献[1,3]）。最近的研究探索了利用对话系统实现动态互动评价的可能性，表明通过实时反馈和自适应问题生成能够有效提升考试的公平性和准确性（见文献[4,5,6]）。

### 1.3 研究问题

1. 如何设计一个基于大语言模型的口试系统，使其能够在实时互动中根据学生回答动态生成后续问题，从而模拟真实口试场景？（见文献[4,5,6]）

2. 如何通过重复实验和统计分析，验证 ChatExaminer 在区分不同技能水平的人工学生（例如表现较差与虽自信但事实不准确的学生）方面的有效性，并确保其评价结果与教学大纲的要求高度契合？（见文献[1,3]）

### 1.4 报告结构与阅读指南

为回答上述研究问题，本文将按照以下结构展开讨论：

- 【引言】介绍项目背景、研究意义和提出的研究问题。
- 【方法】详细描述系统架构、技术实现（包括状态机、问题生成、评价指标等），主要内容参见 README 中的系统架构图和相关技术说明。
- 【实验】介绍通过人工学生进行的重复实验设计，重点展示如何通过统计方法区分不同技能水平的学生，以及系统在模拟真实口试中的表现。
- 【讨论】对实验结果进行分析，讨论系统优势与局限性，并对未来改进方向提出建议。
- 【结论】总结全文，针对提出的研究问题进行逐一回答，并指出系统的实践意义与后续研究方向。

通过上述结构，读者可以清晰地了解到本项目的整体设计理念、技术实现细节及通过实验验证的效果，从而全面认识 ChatExaminer 在口试评价领域中的应用潜力。
